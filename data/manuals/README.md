# Fictional manuals (demo fixtures)

Written for the RepairFlow demo. They are **not** certified repair instructions and describe no real product.
Each file has a JSON front matter block (between `---` lines): source_id, version, published_at, models, title,
and optionally `superseded_by`. Sections start with `## `. Error codes (E-XXX-NN) are language-neutral search keys.
